Kiến Trúc Phát Âm Thanh, IFrame Player API & Giới Hạn Transcoding

1. Phân Tích Kỹ Thuật 14 Câu Hỏi Phát Âm Thanh
1. YouTube API có cho phép lấy raw audio stream không? [FACT] KHÔNG. YouTube Data API v3 và các API chính thức của Google không cung cấp direct URL cho audio stream độc lập.
2. Có được cache/lưu audio không? [POLICY LIMITATION] KHÔNG. Điều khoản cấm lưu trữ, tải xuống nội dung nghe nhìn từ YouTube.
3. IFrame Player API đáp ứng audio UI ở mức nào? [FACT] Rất tốt. Cung cấp đầy đủ các hàm playVideo(), pauseVideo(), seekTo(seconds), getCurrentTime(), getDuration(), onStateChange.
4. Có thể ẩn video UI nhưng vẫn tuân thủ policy không? [ANALYSIS] IFrame Player API cho phép đặt kích thước nhỏ gọn (ví dụ 200x200 hoặc đặt ẩn thị giác phía sau bìa Album Artwork). Để tuân thủ Developer Policies, không được can thiệp xóa logo YouTube hoặc chặn quảng cáo của tác giả.
5. Nếu cần MP3 thực sự thì nguồn nào hợp lệ? [FACT] Chỉ dành riêng cho nội dung người dùng tự tải lên (User-owned content), nhạc Public Domain hoặc Creative Commons có cấp phép.
6. Video 24h xử lý ra sao? [RECOMMENDATION] Áp dụng 100% Logical Episodes. Không tạo 7 bản sao MP3 vật lý chỉ để phục vụ việc chia tập!
