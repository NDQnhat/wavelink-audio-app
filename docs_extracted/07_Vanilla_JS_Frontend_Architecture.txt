1. Triết Lý Thiết Kế Frontend Không Framework
Toàn bộ giao diện người dùng được xây dựng bằng HTML5 ngữ nghĩa, CSS3 hiện đại (Flexbox/CSS Grid/CSS Variables) và Vanilla JavaScript (ES6+ Modules). Không sử dụng React, Vue, Angular hay Node.js runtime trong quá trình production.
2. Cấu Trúc Mã Nguồn Frontend
3. Cơ Chế State Management & Web Audio Player
Player module quản lý thể hiện duy nhất của Audio element, đồng bộ thanh tua nhạc (Seek bar), thời gian hiện tại (currentTime), thời lượng (duration) và trạng thái bộ nhớ đệm (buffered ranges).
Hỗ trợ Media Session API giúp người dùng điều khiển nhạc trực tiếp từ màn hình khóa điện thoại hoặc bàn phím đa phương tiện máy tính.
