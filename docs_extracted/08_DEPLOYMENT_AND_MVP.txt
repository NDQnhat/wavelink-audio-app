08. DEPLOYMENT & MVP ROADMAP
Quy Trình Triển Khai Hạ Tầng Native Systemd, Nginx & Lộ Trình MVP
―――――――――――――――――――――――――――――――――――――――――――――
1. Kiến Trúc Triển Khai Thực Tế (Deployment Topology)
• Frontend: Phân phối toàn cầu qua Cloudflare Pages (Git-based static hosting) với chi phí 0đ, không tiêu tốn RAM hay CPU của VPS.
• Backend Server: Chạy trực tiếp Native Go binary trên Ubuntu Server 22.04 LTS quản lý bởi systemd và reverse proxy Nginx.
2. Lộ Trình Triển Khai MVP (Implementation Roadmap)
