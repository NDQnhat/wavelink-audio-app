08. MYSQL DATABASE DESIGN & TUNING
Đặc Tả Cơ Sở Dữ Liệu MySQL 8.x & Tối Ưu Server Yếu

1. Nguyên Lý Thiết Kế Schema & Ràng Buộc
• Storage Engine: Bắt buộc sử dụng 100% InnoDB để đảm bảo tính toàn vẹn giao dịch (ACID), Foreign Keys và Row-level Locking.
• Character Set: Bắt buộc sử dụng utf8mb4 với Collation utf8mb4_0900_ai_ci nhằm hỗ trợ đầy đủ tiếng Việt có dấu, ký tự quốc tế và emoji.
• Kiểu dữ liệu tối ưu: Sử dụng INT UNSIGNED hoặc BIGINT UNSIGNED cho Primary Key, VARCHAR độ dài hợp lý, ENUM/TINYINT cho trạng thái để tiết kiệm bộ nhớ chỉ mục.
2. Cấu Hình MySQL Tối Ưu Cho Máy Chủ 1GB - 2GB RAM (my.cnf)
3. Chiến Lược Đánh Chỉ Mục (Indexing Strategy)
• Fulltext Search: Đặt FULLTEXT INDEX idx_ft_title_artist ON audios(title) phục vụ tìm kiếm từ khóa với MATCH() AGAINST().
• Composite Index: Đặt INDEX idx_playlist_position ON playlist_items(playlist_id, position) để tối ưu việc load playlist có thứ tự.
• Tránh N+1 Query: Go backend sử dụng các câu lệnh JOIN tường minh hoặc mảng ID (WHERE id IN (...)) thay vì lặp từng query đơn lẻ.
