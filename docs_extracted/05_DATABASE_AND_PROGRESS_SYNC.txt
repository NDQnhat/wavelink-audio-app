1. Nguyên Lý Thiết Kế Schema Tinh Gọn (Lean Data Model)
Hệ thống loại bỏ hoàn toàn các bảng phức tạp của nền tảng nghe nhạc truyền thống (không có bảng audios, mp3_files, artists, albums, genres). Dữ liệu tập trung hoàn toàn vào 4 thực thể cốt lõi: users, youtube_videos, listening_sessions, và listening_progress.

3. Cơ Chế Sao Lưu Tiến Trình Định Kỳ 60 Giây (1-Minute Progress Backup)
Chiến lược đồng bộ tiến trình bảo vệ người dùng trước mọi sự cố mất mạng hoặc sập tab:
• Phía Client: Khởi tạo setInterval 60 giây khi player ở trạng thái PLAYING, đọc player.getCurrentTime() làm nguồn sự thật và gửi PUT /api/v1/sessions/{id}/progress.
• Sự kiện tức thời: Ngay khi người dùng nhấn Pause, Ended, hoặc chuyển tab (document.visibilityState === 'hidden'), client gửi ngay bản tin progress.
• Xử lý ngoại tuyến (Offline Resiliency): Nếu API thất bại (mất mạng), lưu last_unsynced_position vào localStorage và tự động đồng bộ lại khi mạng online.
• Giải quyết xung đột (Conflict Resolution): Server so sánh client_updated_at với bản ghi hiện tại. Chỉ ghi đè nếu thời gian client gửi là mới nhất, loại trừ trường hợp nhận request cũ gửi muộn do trễ mạng.

[FACT] ĐỘC QUYỀN TIẾN TRÌNH: Bảng listening_progress sử dụng khóa duy nhất UNIQUE KEY uk_user_video (user_id, youtube_video_id). Mỗi người dùng với một video chỉ có DUY NHẤT một bản ghi tiến trình nghe, cập nhật qua câu lệnh INSERT ... ON DUPLICATE KEY UPDATE. Không bao giờ phát sinh hàng triệu dòng log rác trong database.

--- TABLE 2 ---
-- 1. Bảng tài khoản người dùng & Guest identity CREATE TABLE IF NOT EXISTS users (     id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,     username VARCHAR(50) NOT NULL UNIQUE,     email VARCHAR(100) NULL UNIQUE,     password_hash VARCHAR(255) NULL,     is_guest BOOLEAN NOT NULL DEFAULT FALSE,     created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,     updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;  -- 2. Bảng cache metadata video YouTube CREATE TABLE IF NOT EXISTS youtube_videos (     id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,     youtube_video_id VARCHAR(20) NOT NULL UNIQUE,     youtube_url VARCHAR(500) NOT NULL,     normalized_url VARCHAR(255) NOT NULL,     title VARCHAR(255) NOT NULL,     description TEXT NULL,     thumbnail_url VARCHAR(500) NULL,     channel_id VARCHAR(100) NULL,     channel_name VARCHAR(150) NULL,     duration_seconds INT UNSIGNED NOT NULL DEFAULT 0,     created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,     updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,     INDEX idx_video_id (youtube_video_id) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;  -- 3. Bảng phiên nghe đang hoạt động CREATE TABLE IF NOT EXISTS listening_sessions (     id VARCHAR(36) PRIMARY KEY, -- UUID v4     user_id INT UNSIGNED NOT NULL,     youtube_video_id VARCHAR(20) NOT NULL,     status ENUM('CREATED', 'READY', 'PLAYING', 'PAUSED', 'ENDED', 'EXPIRED') DEFAULT 'CREATED',     started_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,     last_activity_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,     ended_at TIMESTAMP NULL,     INDEX idx_user_session (user_id, status),     CONSTRAINT fk_session_video FOREIGN KEY (youtube_video_id) REFERENCES youtube_videos (youtube_video_id) ON DELETE CASCADE ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;  -- 4. Bảng vị trí tiến trình nghe (Quan trọng nhất) CREATE TABLE IF NOT EXISTS listening_progress (     id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,     user_id INT UNSIGNED NOT NULL,     youtube_video_id VARCHAR(20) NOT NULL,     position_seconds INT UNSIGNED NOT NULL DEFAULT 0,     duration_seconds INT UNSIGNED NOT NULL DEFAULT 0,     last_state ENUM('PLAYING', 'PAUSED', 'ENDED') DEFAULT 'PLAYING',     client_updated_at TIMESTAMP NULL,     updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,     UNIQUE KEY uk_user_video (user_id, youtube_video_id),     INDEX idx_progress_updated (updated_at) ) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
