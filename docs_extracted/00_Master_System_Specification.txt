1. Giới Thiệu Bản Thiết Kế Tổng Thể (Master Blueprint)
Tài liệu Master System Specification là bản thiết kế trung tâm tổng hợp toàn bộ các quyết định kiến trúc, đặc tả kỹ thuật, ràng buộc phần cứng và lộ trình xây dựng của hệ thống Web Application Nghe Audio Trực Tuyến. Bản thiết kế này phục vụ làm kim chỉ nam xuyên suốt cho toàn bộ đội ngũ kỹ sư triển khai và quản trị hệ thống.
2. Bản Đồ Danh Mục Tài Liệu Kỹ Thuật (Documentation Index)
3. Tóm Lược Ràng Buộc Công Nghệ (Technology Guardrails)
• Frontend: HTML5 ngữ nghĩa + CSS3 Grid/Flexbox + Vanilla JS (ES6+ Modules) tuyệt đối không dùng framework nặng.
• Backend: Golang net/http + Chi v5 (Đóng gói 1 file binary duy nhất dưới 20MB).
• Database: MySQL 8.x InnoDB (utf8mb4, connection pool = 25, buffer pool = 256MB).
• Reverse Proxy & Streaming: Nginx với SSL Let's Encrypt và HTTP 206 qua X-Accel-Redirect / Static alias.
• Media Processing: FFmpeg (1 background worker, nice 19, -threads 1, giới hạn timeout 120s).
