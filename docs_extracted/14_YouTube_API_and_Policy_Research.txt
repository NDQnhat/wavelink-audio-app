1. Điều Khoản Dịch Vụ Của YouTube (YouTube Terms of Service)
2. Phân Tích YouTube Data API v3 & Quota
• Hạn mức mặc định: 10,000 units/ngày cho một dự án Google Cloud Platform miễn phí.
• Tiêu thụ hạn ngạch: Một truy vấn tìm kiếm (Search: list) tiêu tốn 100 units -> Giới hạn tối đa 100 lượt tìm kiếm/ngày.
• Trả lời API: YouTube Data API chỉ trả về METADATA (Tiêu đề, Mô tả, Kênh, Thumbnail) và KHÔNG BAO GIỜ cung cấp direct download URL cho file MP3/Video.
