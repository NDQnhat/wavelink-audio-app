Khi lượng truy cập vượt quá 500 người nghe đồng thời, lộ trình mở rộng không yêu cầu viết lại toàn bộ mã nguồn:
• Bước 1: Di chuyển toàn bộ tệp MP3 tĩnh sang Cloudflare R2 kết hợp Cloudflare CDN Caching (Miễn phí 100% phí egress bandwidth).
• Bước 2: Tách biệt MySQL Database sang máy chủ chuyên dụng Managed DB nếu truy vấn đọc ghi metadata tăng cao.
• Bước 3: Nhân bản Go Backend API chạy song song phía sau Nginx Load Balancer.
