05. SYSTEM ARCHITECTURE & INTEGRATION
Kiến Trúc Tổng Thể & Cơ Chế Phối Hợp Các Thành Phần

1. Mô Hình Kiến Trúc Phân Tách Toàn Cục (Global System Topology)
Hệ thống tuân thủ mô hình phân tách vật lý hoàn toàn giữa Frontend (phân phối tĩnh qua mạng CDN) và Backend (máy chủ đơn nhiệm tự quản lý), kết nối duy nhất qua giao thức HTTPS RESTful API.
2. Phân Tích Dòng Chảy Dữ Liệu (End-to-End Data Flow)
1. Giai đoạn tải trang: Người dùng truy cập domain chính https://audioapp.com -> DNS định tuyến tới Cloudflare Pages Edge -> Trình duyệt nạp bộ nhớ đệm HTML, CSS, JS tĩnh mà không chạm tới Backend Server.
2. Giai đoạn khởi tạo ứng dụng: JS trên trình duyệt kiểm tra phiên làm việc qua lệnh gọi GET https://api.audioapp.com/api/v1/auth/me.
3. Giai đoạn duyệt danh mục: JS gọi GET /api/v1/audios -> Nginx chuyển tiếp tới Go Backend qua Unix Domain Socket -> Go truy vấn MySQL -> Trả về JSON mảng audio.
4. Giai đoạn phát nhạc (Streaming): JS thiết lập src của thẻ HTML5 <audio> tới https://api.audioapp.com/api/v1/audios/{id}/stream -> Nginx chặn và phục vụ trực tiếp tệp MP3 từ đĩa cứng (hoặc qua X-Accel-Redirect) với HTTP 206 Partial Content, hoàn toàn giải phóng Go process khỏi việc giữ kết nối streaming.
